Política de Privacidad

Última actualización: 28 de octubre de 2026

Esta política explica cómo [NOMBRE DEL BOT] trata la información cuando utilizás sus funciones en Discord.

1. Información que puede recopilar

Según las funciones que estén activadas, el bot puede procesar identificadores de usuario, servidor, canal y mensaje; nombres de usuario; contenido enviado mediante comandos o tickets; y datos necesarios para moderación, niveles, economía virtual y configuración del servidor.

2. Para qué se utiliza la información

La información se utiliza para ejecutar comandos, administrar tickets y roles, ofrecer funciones de moderación, prevenir abusos, guardar configuraciones y mantener el funcionamiento del bot.

3. Almacenamiento y conservación

Los datos solo deben almacenarse cuando sean necesarios para las funciones del bot. El responsable debe definir cuánto tiempo se conservan y eliminarlos cuando ya no sean necesarios, salvo que exista una razón legítima para conservarlos.

4. Acceso y divulgación

No se deben vender los datos personales. El acceso debe limitarse a quienes lo necesiten para operar, proteger o mantener el bot. La información solo debe compartirse cuando sea necesario para prestar el servicio, cumplir una obligación legal o proteger la seguridad.

5. Servicios de terceros

El bot utiliza Discord y podría depender de proveedores de alojamiento o bases de datos. Esos servicios pueden procesar información conforme a sus propias políticas.

6. Seguridad

Se deben aplicar medidas razonables para proteger los datos. Ningún sistema puede garantizar seguridad absoluta. Los tokens, contraseñas y credenciales nunca deben publicarse ni compartirse.

7. Derechos y solicitudes

Para solicitar información, correcciones o eliminación de datos relacionados con el bot, contactá al responsable mediante el medio de contacto indicado abajo. Algunas solicitudes pueden estar sujetas a obligaciones legales o a la necesidad de conservar registros de seguridad.

8. Menores de edad

El bot no debe utilizarse para recopilar deliberadamente más información personal de la necesaria. Los responsables de servidores deben respetar las normas aplicables y las condiciones de Discord.

9. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones o las prácticas de tratamiento de datos. La fecha de actualización se modificará cuando se publique una nueva versión.
